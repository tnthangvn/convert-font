# Website Section Report

This is a single-page web app called **WOFF Tool**.

## Main Sections
- **Header** — shows app name and version.
- **Start Section** — lets users open an existing `.woff` file or create a new font set.
- **Workspace Section** — main editing area for managing glyphs and generating output.
- **Footer** — shows internal tool branding.

## Workspace Details
- **Workspace Bar** — shows current font name, glyph count, and back button.
- **Font Name Input** — renames the font.
- **SVG Drop Zone** — imports multiple SVG icons.
- **Glyph Toolbar** — sorts, re-indexes, and sets the starting codepoint.
- **Normalization Panel** — standardizes icon size and alignment.
- **Search Bar** — filters glyphs by name.
- **Glyph List** — displays, renames, reorders, and removes glyphs.
- **CSS Config** — sets the CSS class prefix.
- **CSS Preview** — previews and copies generated CSS.
- **Generate Actions** — exports `.woff` and `.css` files.
- **Status / Error Bars** — show processing state and errors.
- **Download Section** — provides final download links.
